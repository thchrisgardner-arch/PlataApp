# PlataApp

Réplica navegable de estudio de la app móvil de Banco Plata, reconstruida en React + TypeScript + Vite a partir de capturas de referencia. Datos ficticios y operaciones simuladas.

- `app/` — la aplicación (ver [app/README.md](app/README.md)).
- `docs/` — inventario de capturas, notas de revisión, catálogo y referencias externas.
- `scripts/` — scripts de inventario, hojas de contacto, catálogo y utilidades de traducción.

Las capturas originales no se incluyen en el repositorio.
